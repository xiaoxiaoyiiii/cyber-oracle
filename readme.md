## ✨ 核心玩法

| 模式 | 玩法亮点 | 适合场景 |
| :--- | :--- | :--- |
| **☯ 单人问卦** | 自动推算**四柱八字**（年/月/日/时柱）、纳音五行与强弱分布；支持**手摇六爻铜钱**与**长按蓄力**，触发罗盘推演仪式并盖上朱砂印章。 | 测今日运势、学业/搞钱、桃花、破局渡劫 |
| **🤝 双人合盘** | 录入两人昵称、生辰与关系，根据日主五行相生相克测算**天机契合度**与搞笑组合称号。 | 拉上开黑搭子、损友或暧昧对象互测缘分 |
| **🎲 决断问事** | 模拟传统**掷圣杯**（圣杯/笑杯/阴杯），支持**一掷定音**与**三圣杯挑战**，并能识别夜宵、表白、剁手、摸鱼等关键词给出专属断语。 | 纠结一件事到底「做还是不做」 |

### 🎨 细节与交互彩蛋
* **🖼️ 灵符海报导出**：Canvas 实时生成竖版暗金赛博灵符 PNG，可直接保存发群或朋友圈。
* **🔗 URL 分享直达**：三种模式均支持生成带 `#s=` / `#m=` / `#d=` 参数的分享链接，朋友点开直接围观你的签文，还能一键「我也要算」。
* **🔊 合成音效与震动**：纯 Web Audio API 合成铜钱清响、木鱼敲击与五声音阶揭晓音效；移动端支持长按蓄力发光与短震动反馈。
* **🪵 赛博功德木鱼**：顶部自带敲木鱼计数器，随时攒点电子功德退散水逆。

## 🚀 30 秒部署属于你的算命摊

本项目为**纯单文件 HTML（零后端、零构建工具）**，开箱即用：

1. 点击右上角 **Fork** 本仓库（或直接下载 [index.html](https://www.google.com/search?q=https://github.com/xiaoxiaoyiiii/cyber-oracle/blob/main/index.html)）。
2. 进入仓库 **Settings → Pages**，将 **Branch** 设为 `main` / `/ (root)` 并保存。
3. 等待约 30 秒，即可获得你的专属公网 HTTPS 链接，也可以直接丢进任何 Nginx / Caddy 静态目录托管。

## 🛠️ 技术栈

* **HTML5 + Vanilla JavaScript**：原生实现干支历法推算、六十四卦成象与 URL Hash 状态编解码
* **Tailwind CSS (CDN)**：响应式暗黑新中式霓虹视觉布局
* **Web Audio API & Canvas 2D**：零外部音频素材的合成音效与海报实时绘制
